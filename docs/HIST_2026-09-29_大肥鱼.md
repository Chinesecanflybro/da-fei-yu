# 大肥鱼 / DESKTOP PET

## STATUS
- Development project is considered completed.
- Do not treat as an active development task unless user reopens it.

## PROJECT_GOAL
- Windows desktop pet named "大肥鱼".
- Original direction involved a blue DeepSeek pet.
- User wanted to connect it to OpenCode so the pet could display OpenCode agent status rather than only acting as a direct DeepSeek chat pet.

## DEEPSEEK_HARNESS_HISTORY
- DeepSeek Harness bridge was attempted and later abandoned.
- Harness version observed: 1.8.0; dsh 0.1.7-rc.2.
- Official release digests matched local installer assets.
- Harness repeatedly exited with a native Electron/V8 EXCEPTION_BREAKPOINT-type crash.
- Troubleshooting included removing the pet bridge, clean userData, and --disable-gpu; issue remained.
- Decision: stop pursuing Harness integration.

## OPENCODE_DIRECTION
- OpenCode binary observed during audit: opencode-ai v1.18.32.
- Local OpenCode server documented with `opencode serve`, default 127.0.0.1:4096.
- Relevant status/event concepts noted: /global/health, /session/status, /event.
- Goal was OpenCode-agent status integration.

## UI/BEHAVIOR
- User disabled the pink Remielle pet through plugin configuration.
- User wanted the left-click CPU/system-metrics popup removed.
- At one point the pet showed "desktop twitching"; audit found the current instance, roaming disabled, and no window-position changes, suggesting attention should be on status animation/roam-related behavior if ever reopened.
- A later optimization removed unconditional web_view redraw every 1.5s and changed OpenCode health polling to adaptive intervals (OFFLINE 2s, ONLINE 10s), without changing 127.0.0.1:4096.

## WORKFLOW
- This project is now reference/archive memory.
- Preserve design decisions and troubleshooting history, but do not load it for unrelated active projects.
